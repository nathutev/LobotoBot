# LobotoBot 🐝

LobotoBot je rozšíření pro prohlížeč Google Chrome, které slouží výhradně jako **pasivní nápověda**.

Rozšíření **nevyplňuje cvičení za vás**. Celé cvičení děláte sami a učíte se.

### Instalace

1. Otevřete v prohlížeči stránku rozšíření: `chrome://extensions`.
2. Zapněte přepínač **Režim pro vývojáře** (Developer mode) vpravo nahoře.
3. Klikněte na **Načíst rozbalené** (Load unpacked) a vyberte složku tohoto projektu (`LobotoBot`).
